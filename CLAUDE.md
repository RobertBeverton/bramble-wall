# Bramble Wall

Felix & Alex's shared-canon story world (Bramble Wall, Trio Force, wider
shared-canon standalones). Content only: stories, canon and process.

**Start at `docs/process/README.md`.** It gives the read-order for every task
(new Bramble Wall book, Trio Force case file, archive rewrite, review). Use the
`/write-story` command for a new story.

The site lives in the separate Stories repo (`../Stories`), which pulls
`stories/` in at build time. Site-design docs referenced from
`docs/process/README.md` (`docs/plans/...`) live there now. Locked stories go
in `stories/` (series in `stories/<series>/`) with front matter. Never put site
code here.

This canon is deliberately separate from isles-of-yum. Don't pull its
characters, places or rules in here.
